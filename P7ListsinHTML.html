Lists in HTML

There are three types of lists in HTML:

  • Unordered List
  • Ordered List
  • Description List

Unordered List

  • Item 1
  • Item 2
  • Item 3

Ordered List

  1. First Item
  2. Second Item
  3. Third Item

Description List

Term 1
