Character Entities in HTML

Character entities are used to display special characters in HTML.

For example, the less than symbol (<) can be displayed using the character entity < and using entity number <.

The greater than symbol (>) can be displayed using the character entity > and using entity number >.

The ampersand symbol (&) can be displayed using the character entity & and using entity number &.

The double quote symbol (") can be displayed using the character entity " and using entity number ".

The single quote symbol (') can be displayed using the character entity ' and using entity number '.

Copyright symbol (©) can be displayed using the character entity © and using entity number ©.

Trademark symbol (™) can be displayed using the character entity ™ and using entity number ™.
